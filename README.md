# 乖喵桌面宠物

面向 Windows 10/11 x64 的离线桌面宠物。发布物是自包含、未签名的单一 `乖喵.exe`，不依赖 Codex 或预装 .NET。

## 使用

双击 `乖喵.exe`。首次运行时，程序会把自身安装到 `%LocalAppData%\乖喵\乖喵.exe` 并启动安装副本；下载的原始 EXE 保留，可继续作为启动器或新版升级包使用。若本地安装失败，本次会话改用便携模式，开机启动、自动升级和卸载功能会停用。

程序只显示宠物与系统托盘图标，不显示任务栏窗口：

- 左键单击：日常形态挥手；贴屏形态加强按压。
- 左键双击：在“日常”和“肉垫贴屏”之间切换。
- 鼠标移入：按 Codex 的节奏连续播放三次原地扑（`jumping`），随后保持原地待机。一次进入只触发一次；指针需要连续三次离开带 8 DIP 余量的窗口边界才会重新布防，透明帧变化不会再造成扑击/坐正反复抽动。鼠标穿透开启时不触发。
- 左键拖动：移动宠物时按实际水平位移播放 `running-left` / `running-right`，方向变化超过防抖阈值才切换，松开后恢复当前形态并限制在当前屏幕工作区内。
- 右键：打开与托盘图标相同的菜单。
- 托盘“形态”：自动漫游、日常、肉垫贴屏。
- 托盘“立即思考”：播放已修复四肢结构的思考动作一次。
- 托盘“自动跑动（已开启/已关闭）”：明确显示当前开关状态；开启后 6 秒内先跑一次，随后与其他自动造型一样至少保持 45–75 秒的安静间隔。自动小动作连续播放两轮再恢复待机，移动速度仍为上一实现的一半。取消勾选后立即停止自动位移，并保存选择。
- 托盘“立即跑动（测试）”：无须等待，可立刻验证屏幕移动是否工作，且不会更改自动跑动开关。
- 从 1.1.x 升级到 1.2.0 时会一次性重新开启自动跑动，以修复旧配置留下的关闭状态；升级后再从托盘关闭会永久记住，不会自行重开。
- 托盘还可设置鼠标穿透、始终置顶、大小、重置位置和开机启动。开机启动写入后会立即读取注册表校验，并通过托盘提示明确反馈结果。

鼠标穿透开启后，宠物不再接收鼠标；请从系统托盘菜单关闭。设置保存在 `%LocalAppData%\乖喵\settings.json`，日志只保存在本机 `%LocalAppData%\乖喵\logs`。

## Codex 宠物同步

每次启动时，乖喵会在当前用户权限下把内嵌的已校验 v2 图集同步到 `%UserProfile%\.codex\pets\emberwhisk`。当前图集保留已修复的四肢结构，并在画面右侧白色外耳廓加入橙色闪电；其余动作与造型不变。

如果 Codex 正在显示旧图集，切换一次宠物或重启 Codex 即可重新载入。

## 更新与卸载

运行版本号更高的新 EXE 会先关闭安装副本、保留备份、原子替换并执行启动健康检查；失败时自动回滚。托盘“卸载”经过两次确认，默认同时删除偏好设置，不会删除最初下载的 EXE，也不会删除 Codex 宠物包。

## 关于与网络

除用户主动点击“关于 → 检查更新”外，程序完全离线运行，不监听端口、不含广告和遥测。检查更新会访问 GitHub Releases 官方接口 `https://api.github.com/repos/GuaiZai233/pet/releases/latest`；发现新版后，经用户确认才下载 `乖喵.exe`，并校验 Release 返回的 SHA-256、文件版本和受信任下载域名，然后启动现有升级与回滚流程，不静默安装。

此形象由Codex生成，仅供个人使用！

## 安全提示

发布物未进行代码签名，Windows SmartScreen 可能显示未知发布者提示。请用随附的 SHA-256 文件核对完整性。

## 从源码构建

需要 Windows 10/11 x64 与官方 .NET 8 SDK。无需安装 Visual Studio，也无需选择 ASP.NET、C++、Copilot 或其他 Visual Studio 工作负荷。在项目目录运行：

```powershell
.\build.ps1
```

脚本会执行 Release 单文件发布、自测、签名状态检查、哈希生成和源码归档，并把最终文件写入工作区的 `outputs\guai-miao-desktop`。
